Первый релиз на GitHub.

- Список серверов приходит с сервера настроек: если один сервер недоступен, приложение само переключается на следующий.
- Приложение подсказывает, когда вышла новая версия, а слишком старые версии просит обновить.
- Внутри приложения появилось самообновление: скачивание с GitHub, проверка подписи и установка.
