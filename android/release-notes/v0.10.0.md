- YouTube напрямую: видео идёт мимо VPN-сервера, в обход замедления. Приложение само подбирает способ обхода для каждой сети и запоминает его. Если обход не срабатывает, YouTube идёт через VPN, как раньше.
- Включено по умолчанию, выключается в меню ⋮ → «YouTube напрямую». Статус обхода виден в карточке YouTube.
- Трафик YouTube напрямую не расходует дневной лимит.
