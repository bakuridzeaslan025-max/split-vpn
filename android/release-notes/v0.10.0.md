- YouTube теперь идёт напрямую, мимо VPN-сервера, с обходом замедления у провайдера: видео не тратит дневной лимит. Способ обхода приложение подбирает само, для каждой сети отдельно. Если в вашей сети обход не сработал, YouTube, как и раньше, идёт через сервер.
- Пока способ ищется, в карточке YouTube написано «ищу обход…». Когда найден — «YouTube напрямую».
- В новой сети первое открытие видео может занять несколько секунд, пока ищется способ. Дальше приложение его помнит.
- Отключить можно в меню ⋮ → «YouTube напрямую» (при выключенном VPN).
