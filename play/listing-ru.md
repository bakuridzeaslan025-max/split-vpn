# Листинг Google Play — русский (основной язык)

Лимиты консоли: название ≤30, короткое описание ≤80, полное ≤4000 символов.

## Название (≤30)

```
Split VPN
```

## Короткое описание (≤80)

```
VPN только для выбранных сервисов. Остальной трафик идёт напрямую.
```

## Полное описание (≤4000)

```
Split VPN — это VPN, который пропускает через зашифрованный туннель только трафик выбранных сервисов. Всё остальное на телефоне продолжает работать напрямую, как без VPN.

Как это работает
Вы отмечаете, какие сервисы должны идти через VPN: Telegram, YouTube и сервисы Google, WhatsApp и Instagram, X (Twitter), OpenAI и Discord. Приложение добавляет системные маршруты только к сетям этих сервисов. Трафик к ним шифруется и идёт через наш сервер, а банковские приложения, сайты, игры, звонки и всё остальное приложение не затрагивает.

Почему это удобно
• Не замедляет интернет: через туннель идёт только то, что вы выбрали.
• Не расходует батарею впустую: если выбранные сервисы не используются, приложению нечего делать.
• Не нужно каждый раз включать и выключать VPN ради банков, госуслуг и локальных сайтов — они всегда работают напрямую.
• Один экран: кнопка «Включить», список сервисов, статус подключения.

Без аккаунтов и оплаты
Регистрация не нужна. При первом запуске приложение само получает доступ к серверу с помощью проверки Google Play Integrity. На устройствах без сервисов Google можно ввести код доступа.

Стабильная работа в фоне
Вкладка «Автозапуск» помогает отключить оптимизацию батареи и разрешить автозапуск, чтобы система не останавливала VPN. После перезагрузки телефона VPN включается снова, если был включён.

Конфиденциальность
Аккаунтов и персональных данных нет. Содержимое трафика не расшифровывается и не сохраняется. На сервере ведётся только краткий технический журнал соединений для отладки, который удаляется в течение 24 часов. Рекламы, аналитики и сторонних трекеров в приложении нет. Подробности — в политике конфиденциальности.

О VPN
Приложение использует Android VpnService, чтобы направлять трафик выбранных сервисов через зашифрованный туннель к нашему серверу. Трафик остальных приложений через туннель не проходит.

Требуется Android 8.0 или новее.
```
